# React 프론트 시작 코드

Node.js 20.19 이상에서 실행합니다. 먼저 선택한 백엔드 하나를 127.0.0.1:8000에서 실행하세요.

```sh
npm ci
npm run dev
```

브라우저: http://127.0.0.1:5173 . `/api`는 Vite 프록시로 전달됩니다. 서버 포트를 바꾸면 vite.config.js도 수정하세요. 프론트는 한 번에 하나만 켭니다.

`src/api.js`의 FE-01~04를 구현하고 화면을 수정합니다. 백엔드 종류와 무관하게 같은 API를 사용합니다. 시작 코드는 공개 CRUD가 동작하지만 로그인은 미완성입니다. 최종 요구사항은 상위 docs를 읽으세요.

## 로컬 배포와 최종 확인

개발을 마쳤으면 개발 서버를 Ctrl+C로 종료하고 이 폴더에서 실행합니다. 백엔드는 계속 켜 둡니다.

```sh
npm run build
npm run preview
```

http://127.0.0.1:4173 에 접속합니다. 빌드 결과인 `dist/`를 로컬 HTTP 서버로 제공하며 `/api` 요청은 8000번 백엔드로 전달됩니다. 파일을 직접 더블클릭해서 열지 마세요. 코드를 수정했다면 다시 빌드해야 반영됩니다.

개발 실행은 5173번, 로컬 빌드 실행은 4173번입니다. 포트가 사용 중이면 먼저 기존 프로세스를 종료하세요. API 포트를 바꾸면 vite.config.js의 `server.proxy`와 `preview.proxy`를 함께 수정합니다. Vite preview는 이번 과제의 로컬 빌드 확인용입니다. 로컬 실행 절차는 상위 `docs/07_로컬실행안내.md`를 참고하세요.
